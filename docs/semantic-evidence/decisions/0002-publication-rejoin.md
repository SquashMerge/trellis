# Decision 0002: authenticated SCIP facts and publication-time rejoin

- **Status:** prospective docs-only #11A amendment; no deployed importer, checker, schema, or migration
- **Scope:** `../contract-v1.md` and `../publication-rejoin-vectors-v1.md`
- **Amended by:** [Decision 0003](0003-per-document-occurrence-ids.md) (proposed). Occurrence IDs become per document version and extraction context (`occ:v2`), so a byte-identical document at the same `DocumentKey`, under the same native producer ID, version and extraction context has equal r1 and r2 occurrence IDs; a context or producer change makes them differ. Publication rejoin requires a verified r2 native candidate, subject only to the selected-version witness exception below; it mints new r2 provenance and associations and carries no r1 provenance or binding into r2.
- **Compatibility:** #22 canonical bytes, #38 native records, #47 declaration history, #52 revision/warnings. Legacy #26 `SemanticCapture` `formatVersion:1` bytes stay immutable **except** where Decision 0003 regenerates occurrence IDs in its frozen normalized records (pre-release, no backward compatibility).

## Owner decisions and the narrow boundary

The owner approved native-publication rejoin of unchanged-document semantic evidence from an authenticated earlier capture, rather than carrying old provenance or bindings into the new revision, or claiming another producer run (under Decision 0003 an unchanged document's occurrence IDs may be numerically equal across revisions). `derivedFrom.recordKind` names **raw** `occurrence|symbolInformation|relationship`, not destination families. Future #27–#30 use a **new** `CapturedScipFactV1` envelope only; this decision does not edit their paused issues. The full fact digest is `SHA-256(UTF8("trellis.semantic-fact.v1\0") || #22 canonicalBytes(envelope))`. Captured provenance has `derivedFrom:null`; minted proof carries `{provenanceId,recordKind,factDigest}`. Only that verified link permits an r2 proof to retain an r1 `SemanticBasis`. Do not infer calls, dispatch, reference resolution or an `extends|implements|overrides` relationship from raw SCIP flags alone.

## Resolved v1 shape choices

1. **Index-level context:** Validate `Index.external_symbols` and nested relationships recursively, including unknown fields and enum values, under the authenticated original artifact hash. Omit them from document-only envelope/proof inventory: they lack source-document coordinates and cannot establish a document-local destination claim. Never attach one to a document, forge a local anchor or invent a fourth raw kind. No `scope` key exists in the v1 envelope.
2. **Document uniqueness:** Within one authenticated Index, reject any duplicate `Document.relative_path` *before* fact extraction, including two documents with different `language` values. Validate each path against its admitted source root and language/source-set binding. Never concatenate documents or use map overwrite/first-wins. **Empty-language binding (owner ruling #420, 2026-10-29):** An empty SCIP `Document.language` binds to the language Trellis detected for the matching admitted source document only when the producer's pinned profile covers that language. Otherwise reject with a typed admission error. A non-empty language must still exactly match the admitted source language. Compute this binding during single-artifact, batch staging and store admission; never rewrite original artifact bytes. Claims, proof identity and reads use the bound non-empty language.
3. **Ranges:** A required primary occurrence range is precisely one of `legacy` with 3 or 4 nonnegative int32 values; `singleLine` with `{line,startCharacter,endCharacter}`; or `multiLine` with `{startLine,startCharacter,endLine,endCharacter}`. An optional enclosing range is the same variant or explicit null. Reject a legacy and typed variant both present, including conflicting enclosing variants, or a missing/empty primary range. Typed protobuf `snake_case` maps to these exact camel-case JSON field names; every numeric field, including implicit protobuf zero, is present in JSON. Preserve raw `position_encoding` numeric `0` or 1=UTF-8, 2=UTF-16, 3=UTF-32 in the envelope/digest. For `0` (unspecified, whether omitted on wire or explicit), coordinate conversion must use the authenticated capture manifest encoding pinned to this producer version. Reject only if neither artifact nor authenticated manifest declares a valid 1/2/3 encoding; reject an unsupported enum or a conflicting valid artifact/manifest encoding. Never rewrite raw `0` to the conversion encoding. Reject invalid scalar/CRLF positions, reversed ranges or range outside authenticated source bytes. Conversion to UTF-8 measured offsets occurs **after** digesting raw coordinates. Protobuf explicit-default presence is not an identity discriminator: both an absent and an explicitly encoded `0` digest as raw `0`; manifest fallback provides the conversion convention. For an enclosing range, no variant means null (not an empty legacy array).
4. **Field disposition:** The table below is exhaustive for the pinned `scip 0.10.0` generated messages. Decode authenticated binary (not JSON serialization of protobuf); retain original artifact bytes/hash, pinned decoder version and a reproducible envelope inventory. Known display/presentation data may be omitted from the fact digest because the whole authenticated binary artifact hash still protects them. Reject unknown fields at every decoded level and unknown semantic enum/role values rather than silently digesting less than the producer asserted. Changing decoder interpretation or selected fields requires a new envelope version **and digest domain**. A newly captured JSON producer may use the same closed envelope and digest rule only with authenticated original bytes/manifest and a pinned, reproducible raw-field mapping; its JSON must not pretend to be binary SCIP or reuse the immutable legacy #26 `SemanticCapture` example.

| SCIP field (pinned `scip 0.10.0`) | v1 disposition |

The document-only closed envelope has exactly `{formatVersion:1,recordKind,relativePath,positionEncoding,raw}`. Its path is the containing admitted `Document.relative_path`; its raw numeric encoding is 0/1/2/3, with a separately authenticated producer-version manifest fallback required for coordinate conversion when raw encoding is 0. No `scope` key, index-level null coordinate variant, or index-symbol proof exists. For `occurrence`, `raw` has exactly `{range,enclosingRange,symbol,symbolRoles,syntaxKind}`. For `symbolInformation`, exactly `{symbol,kind,displayName,enclosingSymbol}`. For `relationship`, exactly `{sourceSymbol,targetSymbol,isReference,isImplementation,isTypeDefinition,isDefinition}`. String defaults are empty; numeric defaults are zero; boolean defaults are false; only `enclosingRange` may be null. `range` variants have exactly `{encoding:"legacy",values:[...]}`, `{encoding:"singleLine",line,startCharacter,endCharacter}` or `{encoding:"multiLine",startLine,startCharacter,endLine,endCharacter}`. Required nulls and unknown-key rejection follow #22. Reject values outside safe unsigned JSON integers even before attempted canonicalization; signed negative positions/roles/enums fail admission. No producer/fixture IDs, source revision/hash, converted ranges, resolution, dispatch, native anchors, destination family or freshness enter these envelope bytes.

## Authenticated proof and transaction

Bind a captured proof ID to exactly the #22 canonical tuple `{producerId,artifactHash,sourceSetId,sourceRevision,language,relativePath,factDigest}` using `SHA-256(UTF8("trellis.capture-proof.v1\0") || canonicalBytes(tuple))` (full lowercase hash, no ordinal/claim discriminator). Every proof tuple is document-scoped: `language` and `relativePath` are concrete and authenticated against its containing document. `language` is the bound detected language under the empty-language rule above, never an empty raw field. `Index.external_symbols` produces no proof tuple. The tuple fields come from admitted authenticated artifact, manifest and envelope, not a guessed protobuf proof ID. Deduplicate identical envelopes **per authenticated tuple** before deriving the proof ID and before exactly-one lookup; preserve distinct claims with different digest or authenticated context. Check the inventory against the original bytes and reject a digest collision, forged ID, missing match or multiple distinct envelope bindings. A matching digest by itself is neither authentication nor an anchor join.

Native publication validates original artifact/binary digest, manifest and inventory atomically, then converts coordinates and joins A facts to a measured r2 native candidate. A must have identical authenticated bytes/key and **one distinct** compatible r2 source candidate at exact span/kind/source set (measured separately or witnessed by a qualifying selected version below), not a name or nearest overlap. Missing/ambiguous A source, invalid conversion or unavailable measurement fails the entire A tuple; malformed captured artifact fails the entire producer artifact. If another revision publishes despite artifact rejection, publish selected diagnosed `failed` coverage for every requested attributable tuple, without producer facts; cancellation publishes nothing. An independently invoked *later import* uses a compare-and-swap against the published revision: a lost race cannot write a partial overlay. These are separate transaction modes.

Mint new r2 associations/provenance with the separately verified r2 native candidate's occurrence ID, owner, ranges, r2 target revision and destination bytes; never carry r1 provenance or bindings into r2 or rewrite captured basis. Under Decision 0003 that r2 occurrence ID may equal the r1 ID for an unchanged document; equality alone never proves validity. For publication rejoin only, a previously validated selected document-version link may witness the unchanged destination source association instead of decoding and separately checking that anchor again, if document key and content hash match, the selected version link is reused, native producer and extraction context match, and raw capture and semantic producer identity match. For eligible LOCAL only, previously authenticated retained raw, manifest and proof rows may be reused per SCIP document under that witness, keyed by SHA-256 (empty domain) of the original length-delimited `Index` field-2 `Document` payload bytes and the source hash authenticated at admission. Admission persists this internal derived-state identity after complete bounded authentication, bound to capture, language and path; it never hashes a parsed reserialization. An unchanged eligible document is not re-decoded, re-hashed, or reloaded for source association, while every newly minted `derivedFrom` still uniquely resolves its original proof ID, kind and full digest. A narrow witness-aware final validator checks changed measurements and the complete combined output without fabricating a full source map; new admission, FULL, raw replacement and context invalidation retain complete authentication and validation. One LOCAL measured index contains only changed, new or invalidated documents, and current target declarations are looked up selectively. A changed, added, moved, deleted or otherwise invalidated document requires measured destination joining; missing or inconsistent complete reusable input takes FULL fallback or a typed failure, never a guessed association. Reuse only source associations, never the old target resolution, provenance or final answer. Check current destination targets for existence and uniqueness, including deletions and restoration, and mint fresh r2 provenance and associations with original authenticated raw proof and basis. Native candidate validation remains a publication-level failure, and this work remains inside the atomic native/semantic transaction. A changed B does not rejoin B. A fact may target changed B only when exactly one compatible measured r2 B declaration verifies the **same stable syntax ID** as the captured internal target; the new A proof is `possiblyStale`, `staleTarget=false`, and cannot expand. If B has no unique verified same-ID target, omit only A facts dependent on B; independent A facts remain, A gets `partial` coverage with actual `observedRoles` and a diagnostic. A source failure instead makes all A selected `failed`. Genuine producer-external targets stay external; never turn an absent internal target into external. Freshness rule 2 marks every minted r1-basis/r2 proof `possiblyStale` despite unchanged A bytes; changed source bytes are only eligible for #47 stale declaration history. `staleTarget=true` remains invalid in v1. Warnings-v1 and #47 latest eligible tuple/document/returned-declaration scope remain unchanged; #40 traversal and #41 observed importer integration are separate gates.

## Amendment: whole-document source-failure scope (2026-10-25)

**Whole-document source-failure scope (owner ruling 2026-10-25).** The whole-A failure rule applies only to claims that authored a captured r1 semantic association. A valid authenticated occurrence unmatched at both r1 and r2 stays explicitly `unmatched`/skipped and does not fail A. A claim that authored an r1 association still fails all of A if its r2 source anchor is missing or ambiguous. No other rejoin rule changes. See the [owner ruling on #334](https://github.com/SquashMerge/trellis/pull/334#issuecomment-6402339896) and [#89](https://github.com/SquashMerge/trellis/issues/89#issuecomment-6402340238).

## Amendment: several originals per producer (#61, owner ruling 2026-10-26)

A batch admission may carry several original SCIP `Index` artifacts for one producer. Each original keeps its own `artifactHash`, which is the proof tuple's `artifactHash` for every fact of its documents; deduplication stays per authenticated tuple and never merges facts across originals. A source document is assigned to at most one original of a producer in a batch; an `Index` containing a document not assigned to it, or two originals containing one document, rejects the batch atomically. Retained raw capture storage is keyed per original (captures, proofs and per-document wire digests) under one batch selection per producer and revision; there is no producer→single-binary map. `Index.external_symbols` of an original remain authenticated context of that original only. Cross-document and cross-original symbol resolution runs against the complete admitted batch: a target in a not-yet-decoded original is never treated as external, genuinely competing definitions stay ambiguous, and page or original order cannot select a winner. Decoding per `Document` unit without materializing the whole `Index` changes the pinned decoder version to `scip-0.10.0/CapturedScipFactV1/2`; it does not change field interpretation, the envelope, or either digest domain.

## Amendment: module markers under project and package roots (#443, owner ruling 2026-10-29)

An empty primary range (start equal to end) is accepted only for a scip-typescript module-definition occurrence that names its own document. Its module path must equal the document path relative to the producer's project root or the nearest package root. The project root is the descriptor's `projectRoot`, which admission binds to the workspace root. A package root is the closest ancestor directory of the document whose `package.json` the native capture admitted and retained in the revision's config inputs; nested package roots of JavaScript sources are admitted for this purpose. When the scheme carries an npm package name and version, both must equal those of that `package.json` (`HEAD` without a version). The anonymous `. .` package is expected at the project root and for a `package.json` without a string name. The root is never derived from the symbol string, and a suffix match never counts. Any other empty range, a marker that names another document or root, and every reversed range reject the artifact with a typed `InvalidArtifact` error. Single-artifact, batch staging and stored-original rejoin admission apply the same check when decoding the original bytes. A valid marker keeps its raw proof and declared symbol and is skipped at the join: it authors no measured declaration name, reference or call anchor. scip-python markers keep the existing module-path rule.
