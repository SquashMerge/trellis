# Quiet diagram defaults

The diagrams separate a compact presentation from the full cached evidence. No native extraction,
API payload, source snapshot, provider permission or type-resolution claim changes in this update.

## Sequence

Calls, effects, boundaries and exits remain ordered and individually selectable. Compact mode uses
short evidence-category labels instead of full assignment and return source expressions. Known
unsupported boundaries keep their not-expanded/unresolved qualifiers. Notes use quiet rows, not
full-width boxes. Only the exact generated continuation guard without an alternative gets a labelled
conditional rail. Other branches, loops and alternatives keep their frames. Nothing becomes an
unconditional call by presentation.

Select a row for its original full evidence and source action. **Show all steps** restores full labels
and frames as well as the existing full-step behavior. Source reads remain explicit.

## Classes

Start with the focus and its indexed inheritance hierarchy. Use its context menu to choose other
related type references. Members show by default within the diagram size bounds, and fold from **Members** or the class menu. Search results, notices and original relationship evidence stay folded. The optional
**Show all returned classes** control exposes the bounded API result, not all classes in the workspace.
One arrow represents the returned declaration kinds for an ordered class pair. It does not infer a
runtime relationship, composition, dispatch or multiplicity. Full original returned records stay available.

See [class usage](class-diagrams.md) and [implementation contract](quiet-diagram-contract.md).

## Agent-facing evidence

These are frontend defaults. An agent consuming existing structured endpoints still receives their
bounded, revision-tagged evidence. The current ACP answer adapter has no exploration tools; adding
read-only structured queries plus file/text search remains a separate proposed capability.
